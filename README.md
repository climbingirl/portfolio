# Portfolio

Это персональный портфолио-проект, реализованный с использованием HTML, CSS и JavaScript. Проект демонстрирует навыки веб-разработки, включая работу с переводом интерфейса, хранением данных в localStorage, динамическое изменение темы и плавный скролл по странице. Проект разработан с учетом адаптивности и корректно отображается на различных устройствах.

## Функциональность

- **Многоязычность (перевод интерфейса)**  
  Пользователь может переключать язык интерфейса. Текущий выбранный язык сохраняется в `localStorage`, что позволяет сохранять выбор при повторных посещениях сайта.

- **Хранение данных в localStorage**  
  Все пользовательские настройки, такие как выбранный язык и тема оформления, сохраняются в `localStorage`. Это обеспечивает сохранение предпочтений пользователя между сессиями.

- **Изменение темы (светлая/темная)**  
  Пользователь может переключаться между светлой и темной темами оформления сайта. Выбранная тема также сохраняется в `localStorage` и применяется автоматически при загрузке страницы.

- **Плавный скролл**  
  Навигация по странице реализована с плавным скроллом к нужным секциям, что улучшает пользовательский опыт.

 - **Галерея работ:** В портфолио реализована галерея с изображениями проектов, позволяющая удобно просматривать работы.
